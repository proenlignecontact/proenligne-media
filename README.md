# proenligne-media

Mémoire et hébergement des médias du planning de publication Proenligne (Postiz).

- `suivi/regles-editoriales.md` : grille (6h30 texte, 13h visuel, 19h vidéo), réglages Postiz, règles de contenu.
- `suivi/publications.csv` : journal de tout ce qui a été programmé (anti-répétition).
- `suivi/historique-pubs.json` : historique des pubs vidéo du skill `pub-motion-proenligne` (créé au premier lot).
- `suivi/rapports/` : compte rendu de chaque lot hebdomadaire.
- `outils/visuel.py` : génère le visuel fixe 1080×1350 du créneau de 13h.
- `medias/AAAA-MM-JJ/` : fichiers en transit vers Postiz (purgés après 14 jours).

Ce dépôt est public : les fichiers sont lisibles par tous. N'y mettre que des contenus destinés à être publiés.
