# proenligne-media

Mémoire, second-brain et hébergement des médias du planning de publication Proenligne (Postiz).

- `suivi/regles-editoriales.md` : grille (6h30 texte, 13h visuel, 19h vidéo), règle « fiche Google », réglages Postiz, règles de contenu.
- `cerveau/` : second-brain. Une fiche JSON par production, relevés de stats, analyses et journal des décisions (voir `cerveau/README.md`).
- `suivi/historique-pubs.json` : historique des pubs vidéo du skill `pub-motion-proenligne` (créé au premier lot).
- `suivi/rapports/` : compte rendu de chaque lot hebdomadaire.
- `suivi/api-stats.md` : mode d'emploi de l'API de statistiques (à compléter quand elle sera disponible).
- `outils/visuel.py` : génère le visuel fixe 1080×1350 du créneau de 13h.
- `medias/AAAA-MM-JJ/` : fichiers en transit vers Postiz (purgés après 14 jours).

Ce dépôt est public : les fichiers sont lisibles par tous. N'y mettre que des contenus destinés à être publiés, et jamais de clé d'API.
